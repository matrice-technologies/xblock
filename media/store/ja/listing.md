# XBlock · Chrome Web Store listing (Japanese)

## Summary (max 132 characters, shown under the name)

Xの荒らしをワンクリックでブロック。ブロックリストを共有したり、ほかの人のリストを登録したりできます。無料・オープンソース・アカウント不要。

## Description

Xの荒らし、bot、スパムをワンクリックでブロック。もう二度と目に入りません。

XBlockは、Xのすべてのポストにブロックボタンを付けます。クリックすれば、そのアカウントはXでブロックされ、あなた専用のブロックリストに追加されます。リストはコードで共有でき、信頼できる人のリストを登録すれば、そこに載っているアカウントもまとめて処理してくれます。

★ ワンクリックでブロック
• すべてのポストのアクションバーに、ブロックボタンを追加。
• 動作を選べる：Xでブロック、またはXでミュート。
• 演出も選べる：即ブロック、長押しで爆発、そしてマウスでポストを一刀両断する「サムライモード」。
• 盾ボタンはその逆。リストの内容にかかわらず、そのアカウントは決してブロックされません。

★ ブロックリストを共有
• ブロックしたアカウントはすべてあなたのリストに入り、XBK-7Q2M9 のような共有コードが付きます。
• ほかの人のコードを貼り付ければ登録完了。新しく追加されたアカウントもすぐに届きます。
• 登録する前に、リストのアカウントを一覧で確認できます。

★ リストごとに、ルールは自由
• Xでブロック：完全にブロック。相手からもあなたが見えなくなります。
• Xでミュート：タイムラインから消え、相手に気づかれることもありません。
• 非表示：ブラウザ上で折りたたみ。Xでは何も変わりません。
• ぼかし：ブラウザ上でぼかし表示。1クリックで読むこともできます。

★ 一括ブロック
• 1クリックで、Xで処理するよう設定したリストを、フォロワーの多いアカウントから順に処理。
• 1アカウントあたり6〜10秒のペース。Xに求められれば、そのつど一時停止します。

★ どの言語でも動作
• Xのメニューからブロックしても、Xの表示言語に関係なく、XBlockがリストに追加します。
• 拡張機能は英語、フランス語、スペイン語、ドイツ語、日本語、ポルトガル語、インドネシア語に対応。

★ プライバシー重視の設計
• アカウント、メールアドレス、Xのパスワードは不要。XBlockはブラウザ内で匿名のキーを作成します。
• ブロックやミュートは、ブラウザから直接Xに送られます。Xのログイン情報を私たちが目にすることはありません。
• 広告なし、トラッカーなし、売るデータもなし。

★ 無料・オープンソース
拡張機能とサーバーのコードは、一行残らずGitHubで公開しています（MITライセンス）。自分のサーバーで動かすこともできます。
