# XBlock · Chrome Web Store listing (Deutsch)

## Summary (max 132 characters, shown under the name)

Trolle auf X mit einem Klick blocken, Blocklisten teilen und die Listen anderer abonnieren. Kostenlos, Open Source, ohne Konto.

## Description

Trolle, Bots und Spam auf X (Twitter) mit einem Klick blockieren und nie wieder sehen.

XBlock setzt einen Block-Button an jeden Post. Ein Klick, und der Account ist auf X blockiert und landet in deiner eigenen Blockliste. Teil diese Liste per Code oder abonniere die Listen von Leuten, denen du vertraust: Um alle Accounts darauf kümmert sich XBlock für dich.

★ BLOCKIEREN MIT EINEM KLICK
• Ein Block-Button an jedem Post, direkt in der Aktionsleiste.
• Du wählst, was er tut: auf X blockieren oder stummschalten.
• Du wählst, wie es aussieht: sofort, eine Explosion per langem Druck oder der Samurai-Modus, in dem du den Post mit der Maus in Stücke schneidest.
• Der Schild-Button macht das Gegenteil: Dieser Account wird nie blockiert, egal was deine Listen sagen.

★ GETEILTE BLOCKLISTEN
• Jeder Account, den du blockierst, landet in deiner Liste, mit einem Code zum Teilen wie XBK-7Q2M9.
• Füg den Code von jemand anderem ein, um zu abonnieren. Neue Einträge erreichen dich, sobald sie dazukommen.
• Sieh dir die Accounts einer Liste an, bevor du sie abonnierst.

★ DEINE REGELN, LISTE FÜR LISTE
• Auf X blockieren: für immer blockiert, sie sehen dich auch nicht mehr.
• Auf X stummschalten: weg aus deiner Timeline, und sie merken es nie.
• Ausblenden: in deinem Browser eingeklappt, auf X ändert sich nichts.
• Weichzeichnen: in deinem Browser weichgezeichnet, mit einem Klick trotzdem lesbar.

★ MASSENBLOCKIERUNG
• Ein Klick arbeitet jede Liste ab, die auf X wirken soll, die größten Accounts zuerst.
• Alle 6 bis 10 Sekunden ein Account, mit Pause, sobald X darum bittet.

★ FUNKTIONIERT IN JEDER SPRACHE
• Jemanden über das Menü von X blockiert? XBlock setzt ihn trotzdem auf deine Liste, egal in welcher Sprache X läuft.
• Die Erweiterung spricht Englisch, Französisch, Spanisch, Deutsch, Japanisch, Portugiesisch und Indonesisch.

★ PRIVAT VON GRUND AUF
• Kein Konto, keine E-Mail, kein X-Passwort. XBlock erstellt einen anonymen Schlüssel in deinem Browser.
• Blockieren und Stummschalten gehen direkt von deinem Browser an X. Deinen X-Login sehen wir nie.
• Keine Werbung, keine Tracker, keine Daten zum Verkaufen.
