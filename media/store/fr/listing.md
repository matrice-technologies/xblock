# XBlock · Fiche Chrome Web Store (français)

## Résumé (132 caractères max, affiché sous le nom)

Bloquez les trolls sur X en un clic, partagez vos listes de blocage et suivez celles des autres. Gratuit, open source, sans compte.

## Description

Bloquez trolls, bots et spam sur X (Twitter) en un clic, et ne les revoyez plus jamais.

XBlock ajoute un bouton bloquer sur chaque post. Un clic, et le compte est bloqué sur X et ajouté à votre propre liste de blocage. Partagez cette liste avec un code, ou abonnez-vous aux listes des gens en qui vous avez confiance : tous les comptes qu’elles contiennent sont traités pour vous.

★ BLOQUER EN UN CLIC
• Un bouton bloquer sur chaque post, directement dans la barre d’actions.
• Choisissez ce qu’il fait : Bloquer ou Masquer sur X.
• Choisissez son style : immédiat, une explosion sur appui long, ou le mode Samurai, où vous découpez le post en morceaux avec la souris.
• Le bouclier fait l’inverse : ce compte n’est jamais bloqué, quoi que disent vos listes.

★ LISTES DE BLOCAGE PARTAGÉES
• Chaque compte que vous bloquez rejoint votre liste, avec un code de partage comme XBK-7Q2M9.
• Collez le code de quelqu’un d’autre pour vous abonner. Chaque nouvel ajout vous arrive aussitôt.
• Parcourez les comptes d’une liste avant de vous abonner.

★ VOS RÈGLES, LISTE PAR LISTE
• Bloquer sur X : bloqués pour de bon, ils ne peuvent plus vous voir non plus.
• Masquer sur X : disparus de votre fil, et ils n’en sauront jamais rien.
• Cacher : repliés dans votre navigateur, rien ne change sur X.
• Flouter : floutés dans votre navigateur, un clic pour les lire quand même.

★ BLOCAGE GROUPÉ
• Un clic suffit pour traiter toutes les listes réglées pour agir sur X, les plus gros comptes d’abord.
• Un compte toutes les 6 à 10 secondes, avec une pause dès que X le demande.

★ FONCTIONNE DANS TOUTES LES LANGUES
• Vous avez bloqué quelqu’un depuis le menu de X ? XBlock l’ajoute aussi à votre liste, quelle que soit la langue de X.
• L’extension parle anglais, français, espagnol, allemand, japonais, portugais et indonésien.

★ CONFIDENTIEL PAR CONCEPTION
• Pas de compte, pas d’e-mail, pas de mot de passe X. XBlock crée une clé anonyme dans votre navigateur.
• Les blocages et masquages partent de votre navigateur directement vers X. Nous ne voyons jamais vos identifiants X.
• Pas de pub, pas de traceurs, pas de données à vendre.

★ GRATUIT ET OPEN SOURCE
Chaque ligne de l’extension et de son serveur est sur GitHub, sous licence MIT. Vous pouvez même héberger votre propre serveur.
